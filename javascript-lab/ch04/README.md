# 종합 프로젝트

할 일 관리 앱을 만든다.

## 필수 기능

1. 할 일 추가·제목 수정·삭제·완료 상태 전환
2. 전체·진행 중·완료 목록 필터와 건수 표시
3. 빈 제목 입력 차단과 사용자 안내
4. `localStorage` 저장과 새로고침 후 복원
5. 샘플 JSON 파일에서 할 일 불러오기
6. 로딩 표시, 실패 안내, 재시도
7. 역할에 따른 모듈 분리

## 실습 데이터와 통신 범위

- 할 일 데이터는 `{ id: "task-1", title: "DOM 실습", completed: false }` 형태로 통일합니다.
- 새 항목은 제목이나 배열 인덱스 대신 고유한 ID로 식별합니다. ID 생성 함수는 강사가 제공합니다.
- 강사는 정상 데이터, 잘못된 JSON, 필드가 누락된 데이터를 준비합니다.
- JSON 파일은 실습 페이지와 동일한 출처의 로컬 HTTP 서버에서 제공합니다.
- 불러온 데이터는 ID를 기준으로 병합하고, 동일한 ID가 있으면 사용자의 기존 항목을 유지합니다.
- 추가·수정·삭제 결과는 브라우저에 저장합니다. 서버에 데이터를 쓰는 API와 백엔드 구현은 이번 과정에 포함하지 않습니다.

## 최종 확인 시나리오

| 상황 | 기대 결과 |
| --- | --- |
| 정상 제목으로 등록 | 목록과 건수가 즉시 갱신된다. |
| 공백만 입력하여 등록 | 등록되지 않고 안내가 표시된다. |
| 제목 수정·완료 전환·삭제 | 데이터, 현재 필터의 목록, 건수가 일치한다. |
| 새로고침 | 저장한 할 일과 완료 상태가 복원된다. |
| 저장 데이터 손상 | 오류를 안내하고 기본 화면을 사용할 수 있다. |
| 샘플 데이터를 두 번 불러오기 | 같은 ID의 항목이 중복 추가되지 않는다. |
| 불러오기 진행 중 | 진행 상태가 보이고 추가 요청 버튼이 비활성화된다. |
| 404·잘못된 JSON·잘못된 데이터 구조 | 실패를 안내하며 기존 목록은 유지되고 재시도할 수 있다. |

## 확장 기능

다음 기능은 필수 기능을 구현한 뒤에 선택적으로 추가할 수 있다.

- 제목 검색, 정렬, 남은 할 일 개수 표시
- 할 일 마감일과 우선순위 추가
- 클로저, `this`, 프로토타입, 클래스 심화
- 실행 컨텍스트와 이벤트 루프 심화
- 테스트 자동화, 패키지 관리, 빌드 도구
- 백엔드 API 연동, TypeScript, 프런트엔드 프레임워크
