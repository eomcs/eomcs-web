# JavaScript 실습

## 학습 목표

1. 변수, 자료형, 조건문, 반복문, 함수로 간단한 처리 로직을 작성할 수 있다.
2. 배열과 객체를 이용하여 데이터를 구조화하고 검색·변경할 수 있다.
3. DOM을 조작하고 이벤트를 처리하여 사용자와 상호작용하는 화면을 만들 수 있다.
4. JSON과 `localStorage`로 데이터를 저장하고 복원할 수 있다.
5. `fetch`, `Promise`, `async`/`await`로 데이터를 비동기적으로 불러오고 오류를 처리할 수 있다.
6. 코드를 모듈로 나누고 개발자 도구로 문제를 찾아 수정할 수 있다.

## 교육 내용

- 1장. 기초 문법과 데이터 처리
- 2장. DOM과 이벤트로 화면 구현
- 3장. 비동기 통신과 종합 프로젝트
- 4장. 종합 프로젝트 

## 자바스크립트 요약 정리

1. `<script>` 태그, console.log(), alert(), confirm(), prompt()
2. 리터럴과 자료형, typeof 연산자 
3. 변수의 종류, 반복문, 조건문
4. 함수, 애로우 함수, 
6. DOM 조작과 이벤트 처리
7. JSON과 localStorage
8. fetch, promise, async/await
